## Highlights

The Linux desktop was rebuilt twice over this release and has landed on the noctalia Quickshell shell. The first pass replaced dunst with SwayNotificationCenter, gave waybar Nerd Font icons alongside cpu, memory, tray and power modules and a pacman update checker, added nwg-dock-hyprland in Rose Pine, and configured a MangoHud overlay for gaming. The second pass then retired waybar, swaync and fuzzel wholesale in favour of noctalia, which supplies the bar, the launcher and the notification panel from one Quickshell config. The hyprlock configuration was lifted out of hyprland.nix into its own module along the way, so the lock screen is now editable without reading past several hundred lines of window manager config.

That migration left one thing quietly broken: the desktop wallpaper. Noctalia draws its own opaque wallpaper layer in Hyprland's background layer, stacked above anything awww paints, so awww-daemon had been faithfully rendering a layer that nothing could ever see while noctalia showed its bundled default underneath it. The wallpaper is now set through noctalia's IPC and awww-daemon is gone from autostart. The image is also tracked in the repository at `wallpapers/wallpaper.png` and linked into `~/wallpapers` by home-manager, so a machine built from a clean checkout comes up with the right background rather than the shipped placeholder — hyprlock already read that path, and noctalia's wallpaper directory now points at it declaratively.

Gaming picked up a performance tuning script, `setup-gaming-perf`, covering the system-level state home-manager cannot reach. It pins the CPU governor to performance through a systemd unit, rewrites gamemode.ini without the gpu and cpu sections that cannot work under Wayland, and enables the scx_lavd sched_ext scheduler for steadier frametimes on a core-constrained CPU. One caveat worth knowing before it alarms you: `gamemoded -t` fails its renice check when launched from an already-reniced shell, which is an artifact of the self-test rather than a real failure, confirmed by re-running the same test at nice 0.

LocalSend is installed for moving files to and from an iPhone, and starts minimized to the tray so the phone can always find the host. It comes from pacman rather than nix deliberately — it is a Flutter/GTK app and the nix build cannot see the system Mesa drivers on CachyOS, dying with "No GL implementation is available". Because ufw is root-owned system state, a `setup-firewall` target opens the ports it needs: 53317 tcp and udp, plus mDNS on 5353.
